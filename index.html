About
Siraj.

I'm Siraj. I write Flutter in Kochi, mostly for products that move money, where a frozen screen or a wrong number is a support call from someone sending their salary home.

That shapes how I work. State should be predictable, releases should have a way back, and UI should be built from tokens so a redesign is a change rather than a rewrite. I'd rather ship one screen that holds up on four platforms than four screens that each almost work.

I work in English, Malayalam is my first language, and I get by in Tamil.
